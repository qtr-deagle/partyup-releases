# PartyUp for Android

Download builds of the PartyUp app (travel buddy matching for Bulacan).

**Latest APK:** [partyup.apk](https://github.com/qtr-deagle/partyup-releases/releases/latest/download/partyup.apk)

- Requires Android 7.0 or newer.
- Your phone may ask you to allow installs from your browser, since the app is not from the Play Store.

This repo only hosts the app file. More info: [party-up.xyz](https://www.party-up.xyz)
